# Blog Promove Imobiliária

Blog estático da Promove Soluções Imobiliárias — Ubatuba/SP.

## Estrutura

```
index.html              ← Página inicial do blog
artigos/
  mercado-ubatuba-2026.html   ← Artigo 1
```

## Como adicionar um novo artigo

1. Copie um arquivo existente de `artigos/`
2. Renomeie com o tema do novo artigo (ex: `bairros-ubatuba.html`)
3. Edite o conteúdo
4. Adicione o card na `index.html`
5. Faça upload no GitHub
